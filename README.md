# Somali Tech Night (Somtech) 🚀

**Somali Tech Night** waa degel intarneed (website) loogu talagalay munaasabad teknoolojiyadeed oo ka dhacaysa magaalada Oslo, Norway. Degelkan wuxuu martida ka caawinayaa inay ogaadaan xogta munaasabadda, aqoonsadaan speakers-ka, eegaan jadwalka barnaamijka, iyo inay iska diiwaan geliyaan.

---

## 🛠️ Teknolojiyada La Isticmaalay (Tech Stack)

- **HTML5**: Dhisidda qaab-dhismeedka bogga (Semantic HTML Elements).
- **CSS3**: Habaynta muuqaalka, midabada, typography, iyo Flexbox Layout.
- **Google Fonts**: Typography-ga rasmiga ah oo isticmaalaya font-ka **Sora**.
- **Google Maps API**: Khariidad (Map) interactive ah oo muujinaysa goobta munaasabadda.
